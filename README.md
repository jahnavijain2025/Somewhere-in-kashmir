# Somewhere in Kashmir 🌿

**Discover Kashmir. Find your kind of escape.**

Somewhere in Kashmir is a responsive travel website designed to help travellers explore the breathtaking destinations of Kashmir, discover hidden gems, and plan their own journeys. The website combines scenic imagery, an elegant forest-green and gold colour palette, and a user-friendly interface to create an engaging travel experience.

🌐 **Live Website:** https://jahnavijain2025.github.io/Somewhere-in-kashmir/

💻 **GitHub Repository:** https://github.com/jahnavijain2025/Somewhere-in-kashmir

---

## 📌 Project Overview

The purpose of this project is to create a beginner-friendly travel website that presents Kashmir's popular destinations and lesser-known attractions in an attractive and accessible format.

The website allows visitors to explore destination pages, learn about Kashmir's natural beauty, discover hidden locations, and access the itinerary-planning section.

### 🎯 Target Audience

- Travellers planning a trip to Kashmir.
- Tourists looking for destination inspiration and travel ideas.
- Students and young travellers exploring new places.
- People interested in Kashmir's landscapes, culture, and hidden destinations.

---

## ✨ Features

- **Homepage:** An introductory hero section, project overview, destination highlights, and navigation links.
- **Destination Guides:** Dedicated pages for Srinagar, Gulmarg, Pahalgam, and Sonamarg.
- **Hidden Gems:** A section highlighting lesser-known destinations, including Doodhpathri, Chatpal, Lolab Valley, and Gurez.
- **Itinerary Planner:** A dedicated page for planning a personalised Kashmir trip.
- **Interactive Navigation:** A JavaScript-powered mobile navigation menu.
- **Responsive Design:** CSS media queries adapt the layout for desktop, tablet, and mobile screens.
- **Visual Design:** Scenic photography, typography, gradient overlays, and a forest-green, ivory, and gold colour scheme.
- **Consistent Layout:** Shared styling and navigation elements provide a consistent experience across pages.

## 🚀 Getting Started

### Prerequisites

You need a modern web browser and a code editor such as Visual Studio Code.

### 1. Clone the repository

Open your terminal and run:

```bash
git clone https://github.com/jahnavijain2025/Somewhere-in-kashmir.git
```

### 2. Navigate to the project directory

```bash
cd Somewhere-in-kashmir
```

### 3. Open the project

Open the folder in Visual Studio Code:

```bash
code .
```

Alternatively, open the folder manually through VS Code using **File → Open Folder**.

### 4. Run the website locally

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code to preview the website locally.

No backend server or database setup is required for the static website.

## 🌐 Deployment

The website is hosted using GitHub Pages.

To configure deployment for your own repository:

1. Open the repository on GitHub.
2. Navigate to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder.
5. Click **Save**.

GitHub Pages publishes the website from the selected branch.

**Live URL:** https://jahnavijain2025.github.io/Somewhere-in-kashmir/

## 📱 Responsiveness

The website uses CSS media queries to adjust layouts for different screen sizes.

Responsive features include:

- A mobile navigation menu.
- Destination cards arranged in a single column on smaller screens.
- Flexible typography and spacing.
- Responsive image containers and content sections.

The website should be tested on desktop and mobile screen sizes to verify its layout and navigation.

---

## 🎨 Design Approach

The website uses a nature-inspired visual identity to reflect Kashmir's landscapes.

- **Forest Green (`#173d32`):** Represents forests and nature.
- **Ivory (`#f5f0e6`):** Provides a warm, readable background tone.
- **Gold (`#d5ae73`):** Adds subtle highlights and elegance.
- **Playfair Display:** Used for expressive headings.
- **DM Sans:** Used for readable body text and navigation.

The overall design aims to be clean, visually appealing, and easy to navigate.
